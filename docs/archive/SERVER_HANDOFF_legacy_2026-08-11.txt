현재 로컬 컴퓨터에서는 다음 경로가 같은 역할을 한다.

AEGIR_old는 예전 per-view G-buffer 구현이면서 전처리 유틸리티 보관소다.

AEGIR_old 아래의 DN-Splatter .ckpt는 옛 AEGIR 학습 체크포인트가 아니라
AEGIR의 입력 geometry 체크포인트이므로 사용해도 된다.

3. 이번에 새 AEGIR에서 수정한 내용
============================================================

1) per-view G-buffer 학습을 shared Gaussian 학습으로 변경

   예전 AEGIR_old는 카메라마다 독립적인 [H,W] material map을 학습했다.
   새 AEGIR은 하나의 Gaussian scene에 geometry와 per-Gaussian
   albedo/roughness/metallic을 저장하고 모든 카메라가 이를 공유한다.

2) DN-Splatter 3D Gaussian을 실제 planar 2D Gaussian으로 고정

   import 시 가장 얇은 축을 local z normal 축으로 옮기고 그 scale은 버린다.
   학습 파라미터에는 tangent scale 두 개만 있으므로 학습 중 다시 부피가 있는
   3D Gaussian으로 부풀 수 없다.

3) primary G-buffer rasterizer 교체

   일반 gsplat 3D rasterization 대신 공식 2DGS
   diff-surfel-rasterization을 사용한다. expected depth, alpha, normal과
   shared material을 매 view에서 differentiable하게 rasterize한다.

4) DiffusionRenderer depth/normal prior 제거

   data loader와 loss는 prior_albedo, prior_roughness, prior_metallic만 읽는다.
   DiffusionRenderer의 depth/normal 출력은 학습 supervision에 사용하지 않는다.
   화면 확인용으로 rasterized depth/normal을 출력하는 것은 prior 사용과 다르다.

5) emitter split 동작 수정

   emitter를 split할 때 parent를 남기지 않고 두 child로 교체한다.
   child intensity는 각각 절반으로 하여 총 에너지를 보존한다.

6) 회전된 emitter ray intersection 축 계산 수정

   emitter quaternion이 identity가 아닐 때 ray를 local frame으로 변환하는
   행렬 곱 방향을 수정했다. rotated anisotropic emitter의 hit 거리와 MIS,
   visibility 계산이 올바른 축을 사용한다.

7) direct visibility를 IRGS OptiX tracer로 교체

   point-center 근사 shadow 대신 공식 IRGS surfel_tracer를 사용한다.
   shared 2D Gaussian으로 OptiX BVH를 만들고 BRDF/light direct ray의
   differentiable opacity/depth visibility를 계산한다.

   남아 있는 근사:
   secondary indirect bounce 4 rays는 아직 고정 DN SH/DC proxy point를 쓴다.
   direct shadow는 IRGS지만 secondary emitter tracing까지 논문과 완전히 같은
   상태는 아니다.

8) proxy_rgb 제거

   별도의 trainable proxy_rgb는 없다. 단, 위의 secondary indirect bounce를
   위해 고정 sh_proxy_color buffer는 남아 있다. 둘은 같은 것이 아니다.

9) ray budget 수정

   rays_per_step은 더 이상 사용되지 않는 옵션이 아니다. 기본 1024이며
   128x128 raster에서 정확히 32x32 patch를 선택한다.

   primary points: 1024
   BRDF samples per point: 128
   light samples per point: 128 (emitter 사이에 균등 배분)
   direct transport rays: 1024 * (128 + 128) = 262,144 / iteration
   indirect approximation: 1024 * 4 = 4,096 / iteration

10) HDR emitter initialization 유지

   transforms.json frame에 radiance_hdr_file_path가 있으면 HDR radiance를
   emitter bright-region initialization에 사용한다. 없으면 LDR 기반 fallback이
   되므로 FIPT-Real 변환 시 EXR을 float .npy로 보존해야 한다.

11) 테스트

   현재 dnsplatter 환경에서 dataset converter 회귀 테스트를 포함해
   최종 21 tests passed를 확인했다.
   504,015 Gaussians와 262,144 direct rays의 forward/backward도 성공했다.
   transport 부분의 추가 peak VRAM은 약 425 MB였으며 full iteration 측정은 아니다.

현재 로컬 2DGS checkout은 commit
335ad612f2e783a4e57b9cbc4d1e167bd599fc98이다.

  python -c "import torch; print(torch.__version__, torch.version.cuda); print(torch.cuda.get_device_name(0)); print(torch.cuda.get_device_capability(0))"
  which nvcc || true

extension은 반드시 서버 GPU에서 다시 빌드한다.

  cd /home/megapose/hohyun_ws/AEGIR
  bash scripts/install_2dgs_rasterizer.sh
  bash scripts/install_irgs_tracer.sh

설치 확인:

  python -c "from diff_surfel_rasterization import GaussianRasterizer; from surfel_tracer import GaussianTracer; print('extensions OK')"
  python -m pytest -q

주의: 현재 실행 스크립트는 conda env 안의 nvidia/cu13을 찾도록 작성돼 있다.
서버 환경이 CUDA 12.x라면 installer의 CUDA_HOME 자동 탐지는 확인해야 하며,
run_*.sh의 CUDA_ROOT 하드코딩도 서버 환경에 맞춰 바꿔야 한다.

5. FIPT-Real converter 구현 및 검증 결과
============================================================

현재 원본은 온전하다.

  Image/*.exr, Image/*.png
  Rt.txt, K_list.txt
  MiDepth/*.npy
  MiNormalGlobal/*.png
  ImMask/*.png
  segmentation/*.exr

중요: AEGIR_old/scripts/export_fipt_nerfstudio.py는 FIPT synthetic 전용이다.
FIPT-Real용 converter는 현재 AEGIR에 별도로 구현했다.

  scripts/export_fipt_real_nerfstudio.py

현재 생성 및 검증된 출력:

  $WORKSPACE/datasets/aegir_nerfstudio/fipt_real_conference/
    191 frames, 540x360
    transforms.json
    images/frame_XXXX.png
    radiance_hdr/frame_XXXX.npy
    depths/frame_XXXX.npy
    normals_world/frame_XXXX.png
    masks/frame_XXXX.png

  $WORKSPACE/datasets/aegir_nerfstudio/fipt_real_classroom/
    278 frames, 540x360
    transforms.json
    images/frame_XXXX.png
    radiance_hdr/frame_XXXX.npy
    depths/frame_XXXX.npy
    normals_world/frame_XXXX.png
    masks/frame_XXXX.png

Rt.txt는 OpenCV c2w이며 rotation의 Y/Z 축을 뒤집어 Nerfstudio OpenGL c2w로
저장한다. 반올림된 Rt rotation은 SVD로 직교화한다. MiDepth는 ray distance가
아니라 meter 단위 camera-z depth다. transforms.json에는 다음을 명시했다.

  aegir_source_camera_convention = opencv_c2w
  aegir_camera_convention = opengl_c2w
  aegir_depth_convention = opencv
  aegir_depth_mode = z
  depth_unit_scale_factor = 1.0
  normal_space = world

깊이로 계산한 normal과 원본 MiNormalGlobal의 median dot은 conference
0.999965, classroom 0.999975다. AEGIR loader 및 Nerfstudio 공식 dataparser로
모든 image/mask/depth/camera 수를 확인했다. EXR은 clipping 없이 RGB float32
.npy로 보존했다. world normal은 DN-Splatter의 camera-space normal 입력으로
오인하지 않도록 normal_world_file_path라는 별도 필드에 둔다.

6. FIPT-Real 전체 실행 순서
============================================================

아래 변수는 conference 기준이다.

  export WORKSPACE=/home/megapose/hohyun_ws
  export ROOT=$WORKSPACE/AEGIR
  export OLD=$WORKSPACE/AEGIR_old
  export RAW=$WORKSPACE/datasets/raw/fipt_real/conference
  export DATA=$WORKSPACE/datasets/aegir_nerfstudio/fipt_real_conference
  export DN_RUN=$WORKSPACE/external_runs/dn_splatter/fipt_real_conference
  export DR_INPUT=$WORKSPACE/datasets/diffusionrenderer_input/fipt_real_conference
  export DR_PRIORS=$WORKSPACE/datasets/diffusionrenderer_priors/fipt_real_conference
  export GBUFFER=$OLD/outputs/dnsplatter_fipt_real_conference_gbuffers_128
  export PRIORS=$OLD/outputs/dnsplatter_fipt_real_conference_gbuffers_128_diffprior

[A] FIPT-Real -> Nerfstudio 변환

실행 명령:

  conda activate dnsplatter
  cd "$ROOT"
  python scripts/export_fipt_real_nerfstudio.py \
    --scene-dir "$RAW" \
    --output-dir "$DATA"

기존 출력은 기본적으로 덮어쓰지 않는다. 다시 만들 때만 검증 후 명시적으로
--overwrite를 붙인다.

DN-Splatter에서 이 depth를 사용할 때는 Nerfstudio 기본값 0.001을 쓰지 말고
반드시 dataparser 옵션을 다음처럼 지정한다.

  normal-nerfstudio \
    --data "$DATA" \
    --depth-unit-scale-factor 1.0 \
    --load-normals False \
    --load-3D-points False \
    --load-pcd-normals False

MiNormalGlobal은 world-space이므로 DN-Splatter가 기대하는 camera-space
normals_from_pretrain 입력으로 직접 사용하면 안 된다. 위 옵션은 point cloud가
아직 없는 현재 변환 출력에서도 DN dataparser가 안전하게 시작되도록 한다.

[B] DN-Splatter 10k geometry 학습

  conda activate dnsplatter
  cd "$OLD"
  python scripts/run_dnsplatter_init.py \
    --data-dir "$DATA" \
    --output-dir "$DN_RUN" \
    --experiment-name fipt_real_conference \
    --steps 10000 \
    --stable

생성된 checkpoint 선택:

  export DN_CKPT=$(find "$DN_RUN" -path '*/nerfstudio_models/step-000009999.ckpt' | sort | tail -1)
  test -s "$DN_CKPT" && echo "$DN_CKPT"

[C] DiffusionRenderer material prior 생성

AEGIR은 basecolor/albedo, roughness, metallic만 사용한다. normal/depth pass는
요청할 필요가 없다.

먼저 24-frame chunk 단위로 input을 만든다. conference는 191장이므로
start-frame 0, 24, 48, 72, 96, 120, 144, 168을 사용한다.

예: 첫 chunk

  conda activate dnsplatter
  cd "$OLD"
  python scripts/prepare_diffusionrenderer_input.py \
    --nerfstudio-dir "$DATA" \
    --output-dir "$DR_INPUT/chunk_0" \
    --video-name conference_chunk_0 \
    --start-frame 0 \
    --max-frames 24

  conda activate diffusion_renderer
  cd "$OLD"
  python scripts/run_diffusionrenderer_priors.py \
    --repo-dir "$WORKSPACE/external/diffusion-renderer" \
    --input-dir "$DR_INPUT/chunk_0" \
    --output-dir "$DR_PRIORS/chunk_0" \
    --frames 24 \
    --steps 20 \
    --resolution "[256,256]" \
    --decode-chunk-size 4 \
    --model-passes basecolor roughness metallic

VRAM이 부족하면 다음으로 바꾼다.

  --resolution "[192,192]" --decode-chunk-size 1 --cpu-offload

마지막 chunk는 23장이므로 --frames 23을 사용한다.

[D] material prior .pt directory 생성

새 AEGIR loader가 prior_dir에서 frame_XXXX.pt를 읽으므로 먼저 DN view sample을
내보낸 뒤 DiffusionRenderer 결과를 붙인다. 이 .pt 안의 depth/normal이 존재해도
새 AEGIR data loader는 prior로 읽지 않는다.

  conda activate dnsplatter
  cd "$OLD"
  python scripts/export_dnsplatter_gbuffers.py \
    --gaussians "$DN_CKPT" \
    --nerfstudio-dir "$DATA" \
    --output-dir "$GBUFFER" \
    --image-size 128 \
    --max-frames 191 \
    --device cuda

  python scripts/import_diffusionrenderer_priors_to_dir.py \
    --sample-dir "$GBUFFER" \
    --prior-dir "$DR_PRIORS" \
    --output-dir "$PRIORS" \
    --match-chunks

확인:

  test -s "$PRIORS/frame_0000.pt"

[E] 새 AEGIR 학습

긴 SSH 작업은 tmux 안에서 실행한다. 현재 CLI에는 AEGIR checkpoint resume 옵션이
없으므로 SSH 연결이 끊겨 프로세스가 종료되면 자동 재개되지 않는다.

  tmux new -s aegir_conference

tmux 안에서:

  source /home/megapose/miniconda3/etc/profile.d/conda.sh
  conda activate dnsplatter
  cd "$ROOT"

  export CUDA_ROOT="$CONDA_PREFIX/lib/python3.10/site-packages/nvidia/cu13"
  export CUDA_HOME="$CUDA_ROOT"
  export TORCH_EXTENSIONS_DIR="$ROOT/.torch_extensions"
  export PATH="$CUDA_ROOT/bin:$PATH"
  export LD_LIBRARY_PATH="$CUDA_ROOT/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
  export PYTHONPATH="$ROOT"

  python -m aegir.cli train-gaussian-scene \
    --dnsplatter-checkpoint "$DN_CKPT" \
    --nerfstudio-dir "$DATA" \
    --prior-dir "$PRIORS" \
    --output "$ROOT/outputs/aegir_fipt_real_conference_shared_20k.pt" \
    --device cuda \
    --steps 20000 \
    --image-size 128 \
    --max-views 191 \
    --max-emitters 16 \
    --geometry-lr 1e-5 \
    --material-lr 1e-3 \
    --emitter-lr 1e-3 \
    --emitter-final-lr 1e-4 \
    --freeze-start 5000 \
    --freeze-end 15000 \
    --checkpoint-every 5000 \
    --num-brdf-samples 128 \
    --num-light-samples 128 \
    --rays-per-step 1024 \
    2>&1 | tee "$ROOT/outputs/fipt_real_conference_shared_20k.log"

주의: IRGS tracer는 기본으로 켜진다. --no-visibility를 붙이면 논문에 가까워지지
않으므로 디버깅 외에는 사용하지 않는다.

OOM이면 먼저 primary patch만 낮춘다.

  --rays-per-step 512

그 다음에도 부족하면 sample 수를 낮춰 시험한다.

  --num-brdf-samples 64 --num-light-samples 64

최종 비교용 학습은 1024/128/128로 되돌린다.

FIPT-Synthetic 주의사항 (2026-08-12 수정):

  source transforms.json의 카메라 축은 FIPT 공식 loader 기준
  left-up-forward다. Nerfstudio OpenGL right-up-back으로 내보낼 때는
  source c2w 오른쪽에 diag(-1, 1, -1, 1)을 곱한다. source Normal EXR은
  Blender world-space normal이므로, 수정된 c2w rotation의 transpose로
  OpenGL camera-space normal로 변환해서 normals_camera에 저장한다.
  source pose와 Normal EXR을 그대로 복사하면 안 된다.

  2026-08-12에 bathroom/bedroom/kitchen/livingroom 122/222/217/227 frames를
  수정된 convention으로 atomic overwrite 재변환했다. 전 frame pose는
  source_c2w @ diag(-1,1,-1,1)과 max error 0이며, rotation determinant는
  전부 +1, modality 누락은 0이다. 각 scene 처음/중간/마지막 frame에서
  depth로 계산한 geometric normal과 출력 camera normal의 median dot은
  0.99998 이상이다. 재변환으로 기존 bathroom의 잘못된 colmap 폴더도
  제거됐다. 기존 external_runs/colmap_manual의 2026-08-11 FIPT 결과는
  비교 기록일 뿐 재사용하면 안 된다.


HyperSim은 source ray-distance를 프레임별 카메라 모델로 z-depth로 변환한다.
source orientation이 비직교인 ai_015_003도 projection과 orientation을 함께
RQ 분해해서 올바른 SO(3) pose와 프레임별 intrinsics를 만든다. HyperSim
transforms.json에는 top-level fl_x/fl_y/cx/cy를 넣지 않는다. 이 값을 넣으면
Nerfstudio가 프레임별 intrinsics를 무시하므로 다시 추가하면 안 된다.

확정된 pose 정책:

  - transforms.json에 camera pose가 있으면 그 pose를 고정한다.
  - 이 경우 COLMAP은 feature/descriptor matching과 sparse point
    triangulation에만 사용한다.
  - camera pose가 없는 새 데이터만 COLMAP mapper로 pose와 point cloud를
    함께 추정한다.

현재 13개 scene은 전부 pose가 있으므로 모두 fixed-pose 경로다.

구현:

  scripts/prepare_fixed_pose_colmap.py

이 스크립트는 프레임별 intrinsics까지 COLMAP DB에 정확히 넣고,
Nerfstudio OpenGL c2w를 COLMAP OpenCV w2c로 변환한다. matcher의 raw
descriptor match를 공급 pose의 epipolar geometry로 검증한 뒤
point_triangulator를 실행한다. intrinsics/pose refinement는 모두 끄며,
출력 images.bin pose가 입력과 1e-6 이내인지 검사에 통과해야만 다음을
transforms.json에 게시한다.

  ply_file_path: colmap/sparse_pc.ply
  applied_transform: identity 3x4

identity applied_transform은 pose를 바꾸는 값이 아니다. colmap/sparse/0이
생겼다는 이유만으로 Nerfstudio가 예전 COLMAP axis swap을 암묵 적용하는 것을
막아 DN checkpoint와 AEGIR camera가 같은 world 좌표를 유지하게 한다.
