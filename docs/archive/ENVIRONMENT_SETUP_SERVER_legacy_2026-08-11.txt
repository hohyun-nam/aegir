작성일: 2026-08-11

============================================================
0. 결론부터
============================================================

현재 최종 파이프라인은 사실상 다음 두 환경만 있으면 된다.

1) dnsplatter 환경 (필수)

   - DN-Splatter 학습
   - 새 AEGIR shared 2D Gaussian 학습/inspect/export
   - official 2DGS diff-surfel-rasterization
   - official IRGS OptiX surfel_tracer
   - DiffusionRenderer 입력 준비와 prior .pt import

   즉, IRGS와 2DGS rasterizer는 별도 conda 환경이 아니다.
   둘 다 dnsplatter 환경 안에 C++/CUDA Python extension으로 설치한다.

2) diffusion_renderer 환경 (필수, material prior를 새로 만들 때만)

   - DiffusionRenderer inference 전용
   - 모델 의존성과 VRAM 관리가 달라서 dnsplatter와 분리한다.

다음 환경은 현재 서버 최종 학습에는 필수가 아니다.

3) aegir 환경 (legacy, 선택)

   - AEGIR_old의 초기 pure-PyTorch/per-view 구현용으로 만들었던 환경이다.
   - 현재 로컬 aegir 환경에는 DN-Splatter, diff-surfel-rasterization,
     surfel_tracer가 설치돼 있지 않다.
   - 새 AEGIR train-gaussian-scene을 이 환경에서 실행하면 안 된다.
   - 새 서버에서는 특별히 옛 checkpoint를 재현할 목적이 없으면 만들지 않아도 된다.

4) isaacsim 환경 (선택)

   - Isaac Sim 데이터 캡처 전용이다.
   - 이미 캡처한 dataset을 서버에서 학습만 한다면 필요 없다.

3. 서버 GPU/드라이버 먼저 확인
============================================================

환경을 만들기 전에 실행한다.

  nvidia-smi
  gcc --version
  g++ --version
  cmake --version

현재 로컬 build 도구는 다음이었다.

  nvcc CUDA 13.0
  cmake 3.22.1
  gcc/g++ 12.3.0

서버 PyTorch가 해당 서버 GPU architecture를 지원해야 한다. 특히 Blackwell GPU면
오래된 CUDA/PyTorch wheel을 사용하지 않는다. 서버에서 이미 CUDA 13용 PyTorch를
설치 중이면 그대로 맞추는 것이 가장 단순하다.

extension build는 로그인 CPU node가 아니라 실제 NVIDIA GPU가 보이는 node에서 한다.
install script가 torch.cuda.get_device_capability()로 architecture를 잡기 때문이다.

  python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0)); print(torch.cuda.get_device_capability(0))"

5. dnsplatter 환경 생성
============================================================

서버에서 이미 dnsplatter 환경을 만들고 있다면 이 절 전체를 다시 실행하지 말고
6절의 확인부터 한다.

AEGIR_old의 생성 스크립트를 사용한 방법:

  source /home/megapose/miniconda3/etc/profile.d/conda.sh
  cd "$OLD"
  bash scripts/create_dnsplatter_env.sh \
    dnsplatter \
    "$WORKSPACE/external/dn-splatter"

이 스크립트가 하는 일:

  - Python 3.10 conda env 생성
  - setuptools/numpy<2/PyMCubes 설치
  - DN-Splatter editable install
  - 설치된 torch가 CUDA 13이면 CUDA 13 nvcc/runtime Python packages 설치

PyTorch wheel을 별도로 지정해야 하는 서버에서는 환경 생성 전에
AEGIR_TORCH_INDEX_URL을 그 서버에서 사용하는 공식 wheel index로 설정한다.
서버 관리자나 현재 설치 중인 환경이 이미 정한 index가 있으면 그것을 유지한다.

중요: CPU-only torch가 설치된 상태로 다음 단계에 넘어가면 안 된다.

  conda activate dnsplatter
  python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
  ns-train --help >/dev/null && echo "DN-Splatter/Nerfstudio OK"

============================================================
7. 2DGS rasterizer와 IRGS tracer 설치
============================================================

둘 다 dnsplatter 환경에 설치한다. 별도 conda env를 만들지 않는다.

  conda activate dnsplatter
  cd "$ROOT"

  bash scripts/install_2dgs_rasterizer.sh
  bash scripts/install_irgs_tracer.sh

두 스크립트는 현재 활성 환경의 PyTorch/CUDA ABI로 extension을 build하고 그 환경의
site-packages에 설치한다. 다른 컴퓨터에서 빌드한 .so나 build 폴더를 복사하지 않는다.

현재 installer는 기본적으로 conda env 내부의 다음 CUDA toolkit을 찾는다.

  $CONDA_PREFIX/lib/python3.10/site-packages/nvidia/cu13

서버가 CUDA 12.x 환경이면 installer의 기본 cu13 경로는 맞지 않는다. 그 경우
실제 nvcc가 있는 CUDA_HOME을 명시한 뒤 실행한다.

  export CUDA_HOME=/actual/path/containing/bin/nvcc
  bash scripts/install_2dgs_rasterizer.sh
  bash scripts/install_irgs_tracer.sh

GPU가 여러 종류라면 실제 학습할 GPU를 보이게 한 상태에서 build한다.

  export CUDA_VISIBLE_DEVICES=0
  export TORCH_CUDA_ARCH_LIST=$(python -c 'import torch; print(".".join(map(str, torch.cuda.get_device_capability(0))))')

설치 위치 확인:

  python -c "import diff_surfel_rasterization as d; print(d.__file__)"
  python -c "import surfel_tracer as s; print(s.__file__)"

두 경로 모두 dnsplatter env의 site-packages를 가리켜야 한다.

통합 확인:

  cd "$ROOT"
  python -c "import torch; import aegir; from diff_surfel_rasterization import GaussianRasterizer; from surfel_tracer import GaussianTracer; print(torch.__version__, torch.version.cuda); print('AEGIR + 2DGS + IRGS OK')"
  python -m pytest -q

8. diffusion_renderer 환경 생성
============================================================

material prior를 이미 .pt로 갖고 있으면 이 환경은 필요 없다. FIPT-Real
conference/classroom처럼 prior를 새로 만들 scene에는 필요하다.

  source /home/megapose/miniconda3/etc/profile.d/conda.sh
  cd "$OLD"
  bash scripts/create_diffusionrenderer_env.sh \
    diffusion_renderer \
    "$WORKSPACE/external/diffusion-renderer"

이 환경은 다음을 별도로 설치한다.

  torch, triton, diffusers, transformers, accelerate, nvdiffrast,
  omegaconf, image/video packages, OpenEXR

inverse model weights 다운로드:

  conda activate diffusion_renderer
  cd "$WORKSPACE/external/diffusion-renderer"
  python utils/download_weights.py \
    --repo_id nexuslrf/diffusion_renderer-inverse-svd

확인:

  python -c "import torch,diffusers,transformers,nvdiffrast; print(torch.__version__, torch.version.cuda); print('DiffusionRenderer env OK')"

주의:

  - 이 환경에 DN-Splatter나 IRGS를 설치하지 않는다.
  - 새 AEGIR 학습도 이 환경에서 실행하지 않는다.
  - DiffusionRenderer 결과 PNG만 만든 뒤 dnsplatter 환경으로 돌아와 prior .pt에
    import한다.

  raw conversion -------- dnsplatter

  DR input prepare ------ dnsplatter

  IRGS tracer ----------- dnsplatter 안에 설치

10. 학습 실행 전 shell 설정
============================================================

기존 run_warehouse/run_hypersim wrapper에는 대부분 포함돼 있다. 직접 명령을 실행할
때는 다음처럼 설정한다.

  source /home/megapose/miniconda3/etc/profile.d/conda.sh
  conda activate dnsplatter
  cd /home/megapose/hohyun_ws/AEGIR

  export CUDA_ROOT="$CONDA_PREFIX/lib/python3.10/site-packages/nvidia/cu13"
  export CUDA_HOME="$CUDA_ROOT"
  export PATH="$CUDA_ROOT/bin:$PATH"
  export LD_LIBRARY_PATH="$CUDA_ROOT/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
  export TORCH_EXTENSIONS_DIR="$PWD/.torch_extensions"
  export MPLCONFIGDIR="$PWD/.matplotlib"
  export PYTHONPATH="$PWD"

  mkdir -p "$TORCH_EXTENSIONS_DIR" "$MPLCONFIGDIR" outputs

서버 환경의 CUDA toolkit이 cu13이 아니면 CUDA_ROOT만 실제 경로로 바꾼다.

11. 빠른 진단 명령
============================================================

현재 활성 환경 확인:

  echo "$CONDA_DEFAULT_ENV"
  which python
  python -c "import sys; print(sys.prefix)"

모든 필수 import와 CUDA 확인:

  python - <<'PY'
  import torch
  import aegir
  import dn_splatter
  import diff_surfel_rasterization
  import surfel_tracer

  print("torch:", torch.__version__)
  print("torch CUDA:", torch.version.cuda)
  print("CUDA available:", torch.cuda.is_available())
  if torch.cuda.is_available():
      print("GPU:", torch.cuda.get_device_name(0))
      print("capability:", torch.cuda.get_device_capability(0))
  print("aegir:", aegir.__file__)
  print("dn_splatter:", dn_splatter.__file__)
  print("2DGS:", diff_surfel_rasterization.__file__)
  print("IRGS:", surfel_tracer.__file__)
  PY

정상 기준:

  - CONDA_DEFAULT_ENV=dnsplatter
  - CUDA available=True
  - aegir 경로가 $WORKSPACE/AEGIR
  - dn_splatter 경로가 $WORKSPACE/external/dn-splatter
  - 2DGS와 IRGS 경로가 dnsplatter env/site-packages


============================================================
12. 자주 생기는 잘못된 구성
============================================================

1) aegir env에서 새 AEGIR 학습

   증상: diff_surfel_rasterization 또는 surfel_tracer import error
   해결: dnsplatter env로 전환하고 두 extension을 그 환경에 다시 설치

2) extension은 한 env에 설치하고 학습은 다른 env에서 실행

   증상: module not found, undefined symbol, PyTorch ABI error
   해결: build/install/run을 모두 dnsplatter env에서 수행

3) 다른 GPU에서 만든 build 폴더나 .so 복사

   증상: no kernel image, invalid device function, OptiX build failure
   해결: 서버 학습 GPU에서 build/dist를 지우고 installer 재실행

4) CPU-only PyTorch

   증상: torch.cuda.is_available() == False
   해결: 서버 GPU/driver와 맞는 CUDA PyTorch wheel로 dnsplatter env 재설치

5) 새 AEGIR 대신 AEGIR_old가 import됨

   증상: train-gaussian-scene subcommand가 없거나 예전 per-view 코드 실행
   해결: python -m pip install -e "$ROOT", PYTHONPATH="$ROOT", aegir.__file__ 확인

6) 로그인 node에서 extension build

   증상: torch.cuda.get_device_capability() 실패 또는 잘못된 arch로 build
   해결: GPU allocation/tmux session에서 target GPU를 보이게 한 뒤 build

7) CUDA_HOME과 PyTorch CUDA ABI 불일치

   증상: nvcc compile/link error 또는 undefined CUDA symbol
   해결: torch.version.cuda와 CUDA_HOME/bin/nvcc major version을 일치시킴


============================================================
13. 서버 담당자에게 전달할 한 문장
============================================================

새 AEGIR은 dnsplatter Python 3.10/CUDA 환경에서 실행하며, official 2DGS
diff-surfel-rasterization과 IRGS surfel_tracer도 같은 dnsplatter env에 source build로
설치한다. DiffusionRenderer만 별도 diffusion_renderer env를 사용하고, legacy aegir
env는 새 학습에 필요하지 않다.
